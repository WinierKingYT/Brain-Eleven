# Documentation map

Start with the repository `README.md`. Current project state is maintained in
`PROJECT-STATUS.md`; the short next-action summary is `NEXT.md`.

## Current material

- `contracts/` — governing or reusable package contracts that are not root-path
  dependencies of frozen evaluators.
- `programs/` — program-level direction, including Intelligence Graduation.
- `CANARY-GATE-FEASIBILITY-PROPOSAL.md` and `IG05-REACHABILITY-CHECK.md` —
  bounded current decision inputs.

## Historical material

`history/` contains completed plans, reports, independent reviews, generated
evidence, and superseded records. Its files remain available for provenance but
must not be treated as current runtime or release authority.

For precedence and exact classifications, read
`../DOCUMENTATION-AUTHORITY.md`.
