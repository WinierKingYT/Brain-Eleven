# Version vocabulary

This repository uses version labels for different purposes. They must not be
used interchangeably in status claims.

| Label | Meaning |
|---|---|
| **Brain-Eleven v3** | Product/repository identity in current status and README material. |
| **PRE-12** | Historical foundation and repository-consolidation checkpoint. |
| **PRE-13** | Historical post-foundation development line; its quality evidence is not a graduation claim. |
| **IG-00 … IG-09** | Current Intelligence Graduation packages. IG-00 is the only package implemented in this working tree. |
| **Phase 20** | Frozen future Knowledge Engine program. It remains locked until the IG unlock contract passes. |
| **V1** | Existing active SessionStart/context delivery path. |
| **V2** | Shadow task-aware router/authority/compiler path. It is not production default. |
| **baseline tag** | Immutable revision-bound evidence anchor, such as `intelligence-graduation-baseline`. |

“Implemented”, “verified”, “graduated”, “shadow”, and “frozen” retain the
meanings defined in `PROJECT-STATUS.md`; a green CI run does not imply that a
retrieval or extraction quality gate passed.
