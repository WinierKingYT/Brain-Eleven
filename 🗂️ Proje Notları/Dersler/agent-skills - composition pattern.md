# Skill Taxonomy for Agent Design

**Öğretim:** Reusable capability frameworks.

## Bulgu

Skills as composable units:
- Reasoning: planning, reflection
- Tools: API, database, file access
- Integration: LLM interaction, state mgmt
- Security: validation, sandboxing

## Çıkarım

Skills taxonomy → predictable agent design.
Composability > monolithic agents.
