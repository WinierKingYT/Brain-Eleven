# Versions pinned to what is verified working against scripts/*.py in this repo.

# fastapi/httpx note: fastapi 0.103.2 (starlette 0.27.0) is incompatible
# with httpx>=0.28 - starlette.testclient.TestClient passes an `app=`
# kwarg to httpx.Client() that 0.28 removed, so any test using FastAPI's
# TestClient throws `TypeError: Client.__init__() got an unexpected
# keyword argument 'app'`. openai's own httpx floor (>=0.23,<1) pulls in
# a recent httpx by default, so pinning fastapi old and hoping httpx
# stays old too is fragile - bumped fastapi instead of downgrading httpx.

# currently vulnerable; keep the patched transitive dependency pinned.
