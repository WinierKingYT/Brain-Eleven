# IG01-B public corpus versions

`ig-eval-v2/` is the current IG01-B corpus. It supersedes the draft
`ig-eval-v1/` label layout after the independent review found that extraction
conversation fields and blind-label metadata needed to be explicit. The v1
directory is retained as historical provenance only; current CI and package
reports validate v2 and its immutable `ig01b-corpus-v2` tag.
